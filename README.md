# Node.js and Express Development Assignment

A basic real-time chat application demonstrating Node.js, Express.js, MongoDB, Socket.io, Mocha and Chai.

## Features
- Express web server
- MongoDB/Mongoose message storage
- Real-time messaging with Socket.io
- Chat history
- Basic validation
- Mocha + Chai + Supertest testing

## Requirements
- Node.js
- MongoDB running locally

## Run

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```

## Test

```bash
npm test
```
